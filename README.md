# Handy Controller & Configurator Dashboard Web App

A sleek, dark-themed interactive control interface designed for managing Handy device stroke ranges, speeds, and pattern presets in real time.

---

## ⚡ Features

* **Manual Speed & Position Controls:** Smooth vertical sliders for real-time speed adjustments and precise window position tuning.
* **Dual Range Stroke Zone Configurator:** Interactive dual-thumb range slider to set top and bottom stroke boundaries.
* **Pattern Presets:** Quick-access switchers for specialized motion waves (Smooth Fast Wave, Ramp Up, Cooldown Wave, and Sprints).
* **Live System Log:** Real-time terminal feedback monitoring device connectivity and command output.
* **Custom Config & Speed Presets:** Save custom speed limits (Slow, Med, Fast, Max) and zone boundaries on the fly.
